Multi-Server Deployment Strategy

To ensure high performance and security separation, the infrastructure is separated into a **2-Tier Architecture**:

  • Web Tier: Hosts 3 distinct websites using Apache Virtual Hosts listening on HTTP port 80.
  • Database Tier: Isolated MySQL database server configured to accept secure remote connections from Web Server IP.
  • Resource Optimization: Swap Memory space added to both instances to maintain smooth operation on AWS Free Tier.
